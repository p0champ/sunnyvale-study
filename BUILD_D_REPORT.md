# Build D — 3D tools — final PC report

Built:25 local 3D tool builders and their editing/navigation operations. They cover holograms, scene cards, the other seven script tools, all eight thesis tools and all eight thinking tools. Tools have bounded inputs, named parts, detail inspection, saved descriptors and shared grab handles. No paid service, new account or normal-Chrome automation was added.

Holograms load embedded libraryGLB files or public HTTPSGLB URLs (browserCORS required,20MB limit), or use labelled generated component schematics. Explode/turn/resize, part annotations and ground-height alignment work. A6×set test places the virtual eye inside the model and retains its base at floor0. Exact product accuracy requires the actual asset, not a relabelled generic schematic.

Scene cards support actual pointer grab/release reordering, text updates, a persisted script draft, adding/reopening cards, parent transforms/stash and reload. SCRIPT > SCENES opens the saved deck. Actor paths, a movable/lens-adjustable virtual camera with live preview and UI-free libraryPNG capture, procedural sets and movable shadow-casting lights support blocking. Doorways are human-sized and open; NEXT brings each beat to the user. The tower brings individual claim/evidence floors to the user's level. The tension track has a moving first-person camera in a viewing window; it deliberately keeps the headset viewpoint stationary.

The globe uses a public-domain Natural Earth land outline. Radar accepts saved analysis-board film names and averages scored scenes without treating missing scores as zero. Quotes orbit their claims; character relationships move smoothly between acts; affected beliefs visibly wobble and settle. Source/evidence/lineage tools use caller-supplied data and citations. Physical lenses inspect nearby text/shared-browser windows: Bias Lens presents possible loaded wording in a magnifying overlay, and Assumption X-ray reveals supplied proposed premises for the matching argument. They do not alter Chrome, assert an automatic truth judgement or invent premises. Idea synthesis is supplied by Claude; supplying it when creating a forge gives an immediate result on physical merge, with a pending-combinations fallback when intentionally deferred.
